# Fetch Sanity Check

This lightweight repository includes the Fetch/Gymnasium-Robotics evaluation code under
`src/legacy/run_gymrobot_rulebased.py` and the paper table source `table8_cross_platform.tex`.

Raw Fetch episode logs are not bundled in this package. The bundled assets are intended to
document the cross-platform sanity check and provide the evaluation scaffold used in the paper.
